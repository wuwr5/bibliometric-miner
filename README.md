# 文献计量分析工作台（CiteSpace-like）

一个**零第三方依赖**的文献计量与知识图谱可视化工具：直接读取 Web of Science
纯文本导出文件，做共引 / 共现网络、中介中心性、突现检测、聚类与自动标签、
时间线与时区视图，以及**双图叠加、地理视图、Pathfinder 网络缩放、结构变异分析**，
结果在浏览器里交互查看并导出。

后端是 Python 标准库（`http.server` + 自实现算法），前端是原生 JS + Canvas，
**不需要 pip install，也不需要联网下载任何 CDN 资源**。

---

## 1. 快速开始

```bash
# 方式一：双击  start.bat

# 方式二：命令行
cd D:/workbuddy_work/citespace
python server.py 8765
```

浏览器会自动打开 `http://127.0.0.1:8765/`。

仓库已内置一个**合成示例数据集** `sample/wos_demo_synthetic.txt`（798 篇，
由 `make_sample.py` 用固定随机种子确定性生成，**不含任何真实文献**），
用于演示全部功能。启动后在左侧文件列表勾选它 → 设置参数 → **运行分析** 即可。

要分析自己的真实数据：

1. Web of Science 检索后，选择 **导出 → 纯文本文件**，记录内容选
   **"全记录与引用的参考文献"**（这一步很关键，没有 `CR` 字段就做不了共引分析）；
2. 点击界面右上角 **导入 WoS 数据**，可一次选多个 `.txt`（也会落盘到 `data/`）；
   或直接把自己的 `.txt` 放进 `data/` 目录；
3. 左侧勾选要分析的文件 → 设置参数 → **运行分析**。

导出记录数超过 500 条时 WoS 会拆成多个文件，全部选中即可，程序会合并。

## 4. 算法

| 模块 | 实现 | 参考 |
|---|---|---|
| WoS 解析 | 字段标签 + 续行状态机，参考文献按 `作者\|年份\|期刊` 归一 | WoS 导出规范 |
| 共现 / 共引网络 | 同篇文献内两两组合计数 | 文献计量通用做法 |
| 中介中心性 | Brandes 算法，**加权**版：边距离 = 1/w（强连接=短路径），归一化到 [0,1] | Brandes 2001 |
| 聚类 | Louvain 模块度优化（多轮局部移动，固定随机种子可复现） | Blondel 2008 |
| 轮廓系数 | 距离 = 1 − 结构相似度（共现矩阵行向量余弦），在**未剪枝**网络上计算 | Rousseeuw 1987 |
| 聚类标签 | Dunning 对数似然比 LLR（2×2 列联表），备选互信息 MI | Dunning 1993 |
| 突现检测 | Kleinberg 无限状态机 + 动态规划求最优状态路径，强度=相对基线状态的对数似然增益 | Kleinberg, KDD 2003 |
| 布局 | Fruchterman–Reingold 力导向（浏览器端实时迭代） | FR 1991 |
| 剪枝 | Kruskal 最小生成树 / 每节点 top-k 骨架 / **Pathfinder PFNET(q,r)** | Schvaneveldt 1989 |
| 双图叠加 | 施引期刊 ↔ 被引期刊双侧学科分区 + 贝塞尔引用流 + 超几何 z 分数矩阵 | Chen & Leydesdorff 2014 |
| 地理视图 | 国家合作网络 + Natural Earth 110m 底图（等距圆柱投影） | — |
| 结构变异 | 逐年增量建网，新增节点的 ΔM = 移除它的模块度增量、聚类连接度、JS 结构偏移 | Chen 2012/2014 |
| **主题建模（LDA / c-TF-IDF）** | 纯 Python collapsed Gibbs 采样 LDA + Sievert 相关度候选重排；另一条 c-TF-IDF + PPMI-SVD 嵌入 + 球形 k-means 的 BERTopic 式管线 | Blei 2003 / Grootendorst 2022 |
| **引文网络结构** | 库内引用图（DOI 优先，其次 作者-年-期刊）+ Hummon-Doreian 主路径 + Rao-Stirling 结构多样性 + Burt 结构洞 + 幂律 α + k-core | Hummon & Doreian 1989 |
| **趋势预测** | Holt / 阻尼 Holt / AR(1) / AR(2) / GM(1,1) / Logistic / Gompertz 七模型滚动回测集成；Rotolo 四维涌现计分 | Rotolo 2015 |
| **多维融合 KBCA** | 六通道相似度 + Mantel 置换检验 + 加权融合 + Louvain；结构×语义二维综合价值（含 CD 破坏性指数、Uzzi 非典型组合、跨学科熵） | Wu 2019 / Uzzi 2013 |

**关于突现强度**：本工具报告的 `strength` 是突现状态相对于基线状态的对数似然增益
（越大越"意外"），同时给出 Kleinberg 原始权重 `weight`（状态层级之和）与起止年、持续时长。

### Pathfinder 的三个参数

- **r（Minkowski 度量）**：`r=1` 剪枝最强，`r=2`（默认）最常用，`r=∞` 退化为
  最小生成树（已验证：PFNET(n−1,∞) 与 Kruskal MST 完全一致）。
- **q**：替代路径允许的最大边数，留空 = n−1（不限制）。**限定 q 时节点上限 150**，
  因为需要按跳数维护距离矩阵，代价是 O(q²·n²)。
- **距离度量**：`1/共现次数`（推荐，无共现 = ∞）或 `1 − cosine`。
  注意后者所有距离都落在 [0,1]，路径成本很难低于直连边，**剪枝力度会明显偏弱**
  ——这是度量本身的性质，不是 bug。

### 四个新模块怎么读

**主题建模**

- LDA 主题数建议 8–20；报告**困惑度**（越低越好、只在同数据集内可比）与两种一致性
  UMass / PMI。默认 `use_title=True, use_abstract=True`，二元词组自动检测。
- c-TF-IDF 分支不做概率推断，快 5–10 倍，适合先探路。
- 主题标签用的是**前若干个代表词**，不是 CiteSpace 那种 LLR 从标题抽的名字；
  阅读时请以"代表词整体语义"为准，不要只看第一个词。

**引文网络结构**

- **配额率只有 8% 左右是正常的**：引用的绝大多数文献不在你的导出集里。
  只有能解析到库内的那条边，才能用于计算主路径、CD 指数这些指标。
- **CD 指数** ∈ [−1, 1]：正 = 后续工作绕开了它的参考文献（颠覆性），
  负 = 后续工作连它和它的祖先一起引（发展性）。只有至少有一条库内被引的文献才有值。
- **有效规模**（Burt 结构洞）= 网络规模减去冗余约束；**限制度**越小越占据结构洞位置。
- **半衰期**这里报告的是"各年参考文献年龄的中位数"，与 CiteSpace 的
  cited half-life 口径不同：它反映施引文献对新文献的依赖程度，逐年下降是常态。

**趋势预测**

- 七模型滚动回测 + **按回测误差倒数加权**的集成，预测区间 = max(残差区间, 模型分歧区间)
  并按 √步长 放大。
- **会自动剔除不完整尾年**（最后一年的量不足前三年中位数的一半时），日志里会写明。
  这是必须的——所有模型的最后锚点都是最后一个观测值，一个截断的尾巴会把整条
  预测线拖下去。
- **涌现性**按 Rotolo 四维加权：增长 0.30 / 持续 0.25 / 新颖 0.25 / 不确定 0.20；
  "不确定"这里用的是术语所跨 WoS 学科分布的归一化熵。

**多维融合 KBCA**

- 六个通道：文献耦合、共被引、标题+摘要 TF-IDF、LDA 主题分布、共同作者、同学科。
- **Mantel 矩阵**说的是"通道之间是否已 redundant"。本数据集 bc↔cc 的 r=0.76、
  而 TF-IDF 与学科 r=−0.40 —— 说明文本通道确实携带了结构通道没有的信息，
  融合是有意义的而不是重复计数。
- **综合价值 = √(结构 × 语义)**：结构轴 = 加权度 / 介数 / CD；语义轴 = Uzzi 新颖 /
  跨学科熵 / 连通度。用几何平均而非算术平均，避免单一极端值主导。
- Uzzi 新颖性是**独立性零模型下的 z 分数**，期刊天然高度共被引会让绝对值偏大，
  **请按排名读，不要按绝对值读**。

### 结构变异怎么读

- **ΔM** 采用 CiteSpace 的符号约定：定义为"**移除**该新增节点带来的模块度增量"
  （= 基线模块度 − 加入该节点后的模块度）。桥接型节点会拉低模块度，因此移除它模块度回升，
  **ΔM 为正且越大越具结构变革性**；落在单一聚类内部的节点给出负的 ΔM。
  表格同时给出 ΔM 率（ΔM / 基线模块度）便于跨数据集比较。
- ΔM 只在**同一年度内**可比（它依赖基线网络的状态），所以表格同时给出年内 z 值与排名。
- **注意量级**：Top-N 选择下多数高频节点在第 1 年就已出现，后续每年真正的新增节点往往只有个位数，
  因此 ΔM 天然偏小（本数据集 10⁻³ 量级）。判断变革性请**以年内 z 值、聚类连接度为主**，
  不要直接拿不同年份的 ΔM 绝对值横比。
- **聚类连接度** = 新增节点在基线分区中触及的聚类个数，越大说明跨学科跨度越广。
- 每年 ΔM 最强的前 N 个（默认 10）会用完整 Louvain 重新聚类复核一次，
  因为固定分区的估计看不到"两个聚类被合并"这种情况。

## 6. 规模与性能

合成数据 798 篇（2.4 MB，22,274 条参考文献）实测：

- 解析 ~1 s
- 关键词网络（60 节点）：< 1 s
- 被引文献网络（422 节点 / 1,543 边，含中心性 + 聚类 + 标签）：~3.5 s

真实数据 2,046 篇（14 MB，85,005 条参考文献）实测：

- 解析 ~1.2 s；关键词网络（138 节点）不剪枝 ~0.8 s
- Pathfinder（138 节点）：5–16 s（r=2 且距离取 1−cosine 时因几乎不剪枝，最慢 ~19 s）
- 双图叠加 ~0.5 s；地理视图 ~1 s；结构变异 ~0.6 s
- 主题建模 LDA（12 主题 / 6k 词汇 / 40 轮）：**~37 s**；c-TF-IDF 分支 ~5 s
- 引文网络结构 ~2.5 s；趋势预测 ~1 s
- 多维融合 KBCA：**~75 s**（其中 LDA 27 s、倒排 TF-IDF 累加 ~25 s、
  Mantel 15 组 × 199 次置换 ~15 s）——是最重的一个模块，请耐心等。

瓶颈是 Brandes（O(V·E)）与 Louvain。建议：

- 节点数控制在 **300–600**：`最大节点数` 参数默认 500；
- 上万条记录时先调小 `每切片 Top N`（如 25–40）；
- 中心性在超过 1500 节点时会自动截取最强子网络计算。

## 8. 已知局限

1. 只认 WoS 纯文本格式；Scopus / PubMed 需要另写解析器（接口已留好，
   只需产出 `wos_parser.record_to_doc` 同样的字段结构）。
2. LLR 标签目前用词级 unigram，未做名词短语识别，标签可读性略逊于
   CiteSpace 的短语抽取；改进方向是加入停用词扩展 + 二元组合并。
3. 轮廓系数依赖网络自身的连通结构：共被引网络通常给出 0.35–0.5，
   而关键词共现网络在主题分散的数据集上可能只有 0.1–0.25。这是数据特性
   而非算法错误，判断聚类质量请同时看模块度 Q 与 LLR 标签是否可读。
4. 突现检测对被引文献会给出较多结果（被引曲线天然有峰），建议配合
   `最短持续` 与 `最小强度` 过滤，或调大 γ（默认 1.0，越大越保守）。
5. **结构变异没有实现 CiteSpace 的中心性偏离度轴**。CiteSpace 会对每个候选节点
   重算一次 Brandes 中介中心性，代价是每候选 O(V·E)，纯 Python 不可承受；
   这里改用聚类规模分布的 Jensen–Shannon 偏移来刻画结构重排程度。
6. **双图叠加用的是数据驱动的学科映射，不是 CiteSpace 内置的全球底图**。
   WoS 导出不带"期刊→学科"字典，所以本工具按下面顺序推断：施引期刊取其在
   本数据集中出现最多的 WoS 学科类别；被引期刊取引用它的文献的主导类别
   （即"被 citing 文献看到的学科"）；都没有时退回期刊名的关键词规则。
   后果是被引期刊的学科会带 citing 文献的视角偏差（例如一本综合期刊被
   免疫学文章大量引用，就会被归到免疫学）。可用 `assets/journal_discipline.json`
   逐条覆盖。布局也是按学科分带排列，而非 CiteSpace 的双椭圆底图坐标。
7. **地理视图的底图是 Natural Earth 110m**，只包含国家轮廓，不含省/州界；
   纬度裁剪到 [−58°, 84°]（去掉南极）以节省纵向空间。跨日期变更线的合作连线
   不做换日处理，走的是最短球面弧的简化二次曲线。
8. 单机本地服务，未做多用户与权限；数据只在本机 `data/` 目录。

9. **四个新模块均为纯 Python 实现，没有 numpy/sklearn**，所以 LDA 用 Gibbs 采样
   （变分推断会更好但需要矩阵库），嵌入用 PPMI + 随机化截断 SVD 而非 UMAP
   （UMAP 依赖 kNN 图 + 交叉熵优化，纯 Python 代价过高）。含义是：如果你有
   几万篇的语料，建议先用 denoiser 缩减节点数，或者改用外部工具先切分子集。

10. **CD 指数只用"库内引用"**。配额率通常只有 ~8%（绝大多数被引文献不在导出集里），
    所以 CD 的分母很小、波动较大。要得到稳定的 CD 需要把导出范围放大到
    "施引集合 + 被引集合"，即二次检索。

11. **Uzzi 新颖性是独立性零模型下的 z 分数**，期刊天然高度共被引会让绝对值偏大
    （本数据集见到 ±5 到 ±16）。请按排名读，不要按绝对值读；更严谨的做法是
    Uzzi 原文的随机重排 null（代价是 O(pairs × perms)，目前没有做）。

12. **Mantel 检验对配对做了子抽样**（默认 2 万对）。全量版本是 O(n² × perms)，
    在 200 万对上要跑数十亿次操作；2 万对 + 199 次置换给出的 p 值分辨率是 0.005，
    远够用于判断"通道是否冗余"。

13. **趋势预测的年度序列只有 10 个点**。这已经是外推的极限——不要指望 3 年以上的
    预测有多少信息量，请把它当成"方向和量级的定性参考"。预测区间取残差项与
    模型分歧项的较大者，因此模型越不一致，区间就越宽——这是有意为之，
    用来避免单一模型碰巧拟合好最后几个原点就给出一个虚窄的区间。
